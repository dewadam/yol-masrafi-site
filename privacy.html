Privacy Policy

Yol Masrafi is a personal automation tool used only by its owner to upload videos to the owner's own YouTube channel.

What data is accessed

The tool requests the YouTube upload permission (youtube.upload) for the owner's Google account. It uses this permission only to upload videos that the tool itself creates. It does not read, collect or store any personal data, viewing data or content belonging to other people.

How data is stored

The authorization token is stored as an encrypted secret in the owner's private GitHub repository settings and is used only to perform the uploads.

Sharing

No user data is shared with, sold to or transferred to any third party.

Google API Services User Data Policy

Yol Masrafi's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Contact is available through the "Yol Masrafi" YouTube channel.
